# 🇩🇪 Wilkommen im Medienpaket

## Dokumentation (Übersicht)

Willkommen bei der Dokumentation zum Medienpaket der Feuerwehr. Dieses Repository dient als zentrale Anlaufstelle für medienbezogene Aufgaben von freiwilligen Feuerwehrleuten und andere damit verbundene Anwendungsfälle.
Dies ist ein privates Projekt.

Grundlegende Richtlinien für Fotografie und den Umgang mit Medien im Rettungsdienst.

Die Standardsprache ist Deutsch. Für ein internationales Publikum wird lediglich eine Basisversion in englischer Sprache bereitgestellt.

Die Standardsprache ist Deutsch. Eine englische Version für ein internationales Publikum...

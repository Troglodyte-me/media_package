# Glossary

# Abbrivations / Abkürzungen
#### AA
Alkaline battery (AA)

#### AF
Autofocus (AF)

#### BLN-1
Olympus BLM-1 Li-Ion battery

#### BLS-1
Olympus BLS-1 Li-Ion battery

#### CCD
Charge-Coupled Device (CCD) image sensor

#### CMOS
Complementary Metal-Oxide-Semiconductor (CMOS) image sensor

#### Li-Ion
Lithium-Ion (Li-Ion) rechargeable battery

#### LR44
Button cell battery (LR44)

#### MF
Manual Focus (MF)

#### MFT or m4/3
Micro Four Thirds / MFT-Systemkamera

#### MP
Megapixel (MP) = 1 million pixels

#### P/K
Pentax / K-Mount (P/K) camera lens mount

#### SD
Secure Digital (SD) memory card, also: 
* **SDHC** = Secure Digital High Capacity (SDHC)
* **SDMC** = Secure Digital MultiMediaCard (SD/MMC)
* **SDXC** = Secure Digital eXtended Capacity (SDXC)

#### SLR
Single Lens Reflex (SLR) = Spiegelreflexkamera
